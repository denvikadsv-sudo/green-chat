# Green Chat — веб-чат для WhatsApp на GREEN-API

Минималистичный интерфейс отправки и получения текстовых сообщений WhatsApp.
Внешний вид — по мотивам WhatsApp Web. Стек: React 19 + Vite, без UI-библиотек.

## Запуск локально

Требуется Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:5173
```

Прочее: `npm run build` (сборка в `dist/`), `npm run preview`, `npm test` (unit-тесты).

## Как пользоваться

1. В личном кабинете [GREEN-API](https://console.green-api.com) создайте инстанс WhatsApp и авторизуйте его (QR-код).
   В настройках инстанса оставьте **пустой** `webhookUrl` и включите уведомления о входящих (`incomingWebhook`)
   и исходящих сообщениях/статусах — получение работает через HTTP API (`ReceiveNotification`).
2. Откройте приложение, введите `idInstance` и `apiTokenInstance` → «Войти».
3. Нажмите «+», введите номер получателя (`+7 999 123-45-67`, `8 999…` тоже подойдёт) → «Создать чат».
4. Напишите сообщение (Enter — отправить, Shift+Enter — перенос строки).
5. Ответ получателя появится в чате автоматически.

## Как это устроено

- Отправка: `POST {apiUrl}/waInstance{id}/sendMessage/{token}` с `chatId = <номер>@c.us`.
- Получение: непрерывный long-polling `receiveNotification` → обработка → `deleteNotification`
  (строго последовательно, подтверждение отправляется даже при ошибке разбора, чтобы очередь не блокировалась).
- `apiUrl` определяется автоматически (`https://api.green-api.com` или `https://{первые 4 цифры id}.api.green-api.com`
  для 10-значных id); при необходимости задаётся вручную в разделе «Дополнительно» на экране входа.
- Статусы доставки (`sent` / `delivered` / `read`), сообщения, отправленные с телефона, и дедупликация эхо-уведомлений.
- При сбоях сети — повтор с экспоненциальной паузой; неудачные сообщения можно отправить повторно.
- Неверные учётные данные или неавторизованный аккаунт — понятное сообщение на экране входа.
- Учётные данные и история чатов хранятся в `localStorage` браузера (на сервер не отправляются).
- Адаптивная вёрстка: на узких экранах список чатов и переписка переключаются.

Структура: `src/api` (клиент GREEN-API), `src/state` (reducer, опрос), `src/utils` (разбор уведомлений, номера),
`src/components` (экран входа, список чатов, окно чата).
